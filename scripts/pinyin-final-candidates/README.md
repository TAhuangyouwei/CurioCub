# o / eng / ong 候选试听

当前只提供试听，尚未覆盖 `assets/audio/pinyin-basic` 的正式录音。

来源：项目已使用的 davinfifield/mp3-chinese-pinyin-sound，Unlicense。
https://github.com/davinfifield/mp3-chinese-pinyin-sound

从完整一声源文件中提取韵母部分，保持原音高与语速：

- o：`wo1.mp3` 的 0.55～0.95 秒。
- eng：`deng1.mp3` 从 0.20 秒至结尾。
- ong：`dong1.mp3` 从 0.20 秒至结尾。

处理：24kHz 单声道、24kbps MP3，首尾各8ms淡入/淡出，末尾补120ms静音，峰值上限0.4且增益不超过2倍。发音和截取边界尚待试听确认，文件可解码、时长和音量检查不代表教学读音已经审核通过。
